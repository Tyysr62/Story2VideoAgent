# M2.1 分镜声音与视频 Prompt

用户已在声音方案讨论后要求继续实施。保持最多 20 个镜头、云端生成、本地 FFmpeg 合成、逐模块测试和大版本交付后询问 GitHub 推送的约定。

## 范围

首版使用 HeyGen Video 1 的原生声音。独立 TTS、声音克隆、自动口型修复和全片配乐混音不在本轮。角色音色为提示词描述，界面明确不保证固定音色。

分镜增加可选 audio：silent（完全静音）、ambient（仅环境声）、speech（对白或旁白）。对白绑定项目角色 ID，区分画内/画外；旁白与对白分别存储。无 audio 的历史镜头继续按静音处理，不自动修改数据库中的历史分镜。项目分镜保存统一的旁白与角色声音描述，避免将音色混入视觉身份或造型而触发重新生图。

校验不存在的说话角色、画内发声角色未出镜、静音/环境声模式携带人声、speech 没有台词、空台词和超长字段。短片不强制说话。片段暂不生成背景配乐，避免跨镜头音乐跳变。

## Prompt

新增有版本号的纯函数编译器，T2V 描述主体/场景/动作/摄影/风格，I2V 强调从首帧延续、动作顺序、运镜和连续性。结构化声音是人声内容的唯一来源；自由视频要求只描述视觉，编辑页提示该边界。角色声音使用稳定 ID 与身份描述定位，名称只供 UI 展示。字幕默认关闭。

编译后的实际 Prompt、声音计划、音色描述与生成参数归档；音色或台词变化使相关视频失效，首帧仍可复用，并要求重新确认整组清单。旧视频和原始 Prompt 不覆盖。

## API 与音轨

HeyGen 官方文档说明模型原生生成场景声音，但 OpenRouter 实时目录 generate_audio=false，与介绍存在歧义。对 HeyGen 使用模型默认原生音轨，不发送未经核实的开关；静音由最终合成确定性消音。其他模型仅在目录明确支持音频时开启；不支持时在收费请求前拒绝有声计划。保留任务 ID 恢复机制，不自动重复收费。

FFmpeg 支持无声、有声、短音轨的混合片段。逐片段统一视频参数、补齐/截取音频到视频长度，然后按顺序拼接。明确静音片段在成片中静音；历史未设置音频的片段也静音。无参数的底层合成默认保留已有音轨。原始云端片段保持原样归档，不宣称已生成的语音逐字正确。

## 验收

1. 声音 Schema/持久化/导演契约/中文编辑界面测试通过，再进入 Prompt 模块。
2. T2V/I2V、台词引用、音频能力分支、归档与局部缓存失效测试通过，再进入合成模块。
3. 使用真实 FFmpeg 测试有声/无声混排、静音强制执行、顺序与时长、短音轨补齐、原文件不覆盖。
4. 全量单测、类型检查、构建、浏览器操作和真实音视频联调，重启本地服务。真实 HeyGen 语音质量、开关行为与中文口型需通过页面单镜头费用确认后验证，本轮不自动消费账户额度。
