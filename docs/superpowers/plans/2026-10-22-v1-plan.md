# Story Agent V1 Implementation Plan

> **For agentic workers:** Execute sequentially following superpowers:test-driven-development and verification-before-completion. The user requires a passing module gate before starting the next module.

**Goal:** Deliver a local Pi/DeepSeek storyboard → user approval → OpenRouter cloud image/video → playable composition loop with AI-selected 1–20 shots. User changed the initial mock-only scope to API generation; offline fixtures remain for tests/demo only.

**Architecture:** Pi controls a single structured storyboard proposal tool. SQLite is the authoritative project/job store; FFmpeg executes media tasks outside the agent. The browser uses the same revision-aware HTTP API as integration tests.

**Tech Stack:** TypeScript, pinned Node 22, Pi SDK 1.4.0, Fastify, React/Vite, node:sqlite, Zod, FFmpeg, Vitest, Playwright.

## Delivery rules
Use local commits after passing gates; no push or deployment. New independent repository on codex/v1; preserve the ERP repository and discussion draft. `.env.local`, data, reports and node_modules are ignored. V1 includes real cloud API adapters but makes no live-provider quality or RL training claim without the corresponding validation.
