# M2.1 声音与 Prompt 实施计划

> 本会话按 executing-plans 执行，每个模块通过测试后才进入下一个模块。

**目标：** 可编辑的分镜声音规划、区分 T2V/I2V 的确定性 Prompt、保留声音的成片。

**架构：** Zod 声音契约与 React 编辑器；纯函数 Prompt 编译；OpenRouter 媒体适配；FFmpeg 本地音轨归一化。复用现有生产库、审批、任务恢复和 ZIP 导出。

**技术栈：** TypeScript、Zod、Pi SDK、React、Vitest、Playwright、FFmpeg。
