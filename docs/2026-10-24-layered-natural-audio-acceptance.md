# M2.2 分层声音与自然台词

## 问题与改动

原始契约已允许 speech 模式同时保存 ambience 和 soundEffects，但界面将 silent/ambient/speech 展示成三选一，容易误解成人物声音与环境声互斥。导演规则强调可以不说话，缺少如何用角色互动推进剧情的指导；视频编译器只允许列出的“人声内容”，对呼吸、轻笑和叹息等表演说明的执行边界不清。

现保留原数据结构：开启声音后同时编辑环境声、音效、对白、旁白，按实际人声内容派生 mode。增加/删除人声不清空背景层。临时静音可恢复本次未保存内容，保存静音或明确重新载入后不恢复已丢弃的草稿；普通轮询不应重置本地编辑会话。

导演增加有对象、符合人物关系的短句互动与回应，减少以旁白总结代替人物说话；适量口语和语气词，仍保留必要留白，不强制每镜说话或机械堆词。准确原文放 text；轻笑、吸气、叹息、欲言又止、停顿放 delivery；纸张“沙沙”等放 soundEffects，不能念成对白。编译器要求原文保持、表演说明执行而非朗读，指定环境声在人声期间持续、背景不能盖住对白，并给反应和动作留时间。没有新增 TTS 服务或模型参数。

## 缓存与历史

声音视频 Prompt 版本升为 story-video-v2.2，实际编译文本和参数继续随生产库归档、ZIP 导出。旧故事和台词不自动改写，旧原片不修改或删除；视频缓存与整组确认会因新视频配置失效，已有首帧仍可复用。新效果需重新审阅清单、确认费用再生成；没有自动重提收费请求。旧未完结云任务仍有版本保护。

## 验证边界

声音状态测试先失败再通过；实际 Pi 运行时的 system Prompt、结构化混合声音输出和视频编译契约共 57 项定向测试通过。浏览器测试覆盖同屏编辑混合层、原文与环境同时保存/重载、临时静音恢复、保存静音后的草稿隔离、同项目显式重载，以及真实 FFmpeg 测试音轨、生产库混合 Prompt 导出与移动端布局。

独立复核发现同项目同 revision 重载可能复活已丢弃 ref 草稿的问题，已通过显式编辑会话隔离修正；该路径已在旧实现失败的浏览器测试中复现。界面截图已人工查看。本次使用离线模型传输替身与真实 FFmpeg 验证链路，没有额外付费调用来评价模型表现。测试证明结构与请求符合设计，不能证明真实生成的台词数量、语气自然度、音量或跨镜头音色已达到要求；新真实结果仍需试听评估。

最终完整 `npm run verify` 通过：类型检查、23 个文件共 183 项自动化测试、生产构建、15 项浏览器联调。4 条声音 E2E 同时覆盖保存静音后清除草稿、同版本显式重载清除草稿、后台版本轮询保留草稿与混合内容导出；后两项均先复现失败再修正。独立复核确认草稿问题消除。集成测试按镜头 ID 断言旁白和静音，避免并发写入顺序造成偶发假失败。
