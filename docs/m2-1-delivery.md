# M2.1：分镜声音、视频 Prompt 与音轨合成

日期：2026-10-23。用户在声音方案讨论后要求继续，按模块依次实施与测试。本版使用 HeyGen Video 1 原生音频，不新增密钥或独立 TTS 服务。

## 已交付

- 分镜支持完全静音、仅环境声/音效、角色台词/旁白。角色台词绑定稳定身份 ID，区分画内与画外发声；旁白独立保存，可以为空。
- 全片旁白与角色声音描述保存在分镜 audioProfile，独立于视觉身份与造型；可编辑、清除、保存。该描述只是原生生成约束，不保证固定音色。
- DeepSeek 导演工具增加声音字段与规划要求，允许无台词/无旁白，限制短片内的动作与说话负荷。旧分镜不自动迁移或添加声音；缺少 audio 的镜头继续静音。新导演输出遗漏声音时保守补为静音。
- 有版本号的纯函数编译器区分 T2V 与 I2V：前者描述主体/场景/风格，后者保持首帧并强调后续运动。结构化声音统一编译到最终 Prompt，默认无字幕、无逐镜配乐。
- 实际请求 Prompt、声音计划、音色描述、模型配置、片段与成片进入生产库与 ZIP。台词或相关音色变化仅使对应视频失效，首帧和未受影响视频仍可复用，整组清单须重新确认。
- HeyGen 使用上游默认原生声音，不发送有歧义的 generate_audio 开关；其他模型在目录明确支持声音时才接受有声计划。
- FFmpeg 将有声/无声片段统一为 H.264 720p/24fps 与 AAC 48kHz 双声道；补齐无声片段、短音轨，截断超长音轨，保持声音相对视频的起始偏移。用户明确静音的镜头在成片中静音，云端原片保留不覆盖。
- 要求声音却返回无音轨时，暂停并保留原片，不自动再次提交费用。旧编译器留下未完成云任务时，阻止因新输入指纹而另开付费任务。

## 模块验收与问题修复

1. 声音 Schema 的 10 项缺失行为先失败，再实现并通过；导演契约、历史兼容、持久化等共 40 项模块测试与声音编辑 Edge 测试通过后进入 Prompt 模块。
2. Prompt 编译、能力分支与局部失效先复现旧行为，再实现；44 项模块测试通过，另外 12 项 V1 workflow/integration 回归通过。
3. 真实 FFmpeg 测试先证明旧合成没有音轨，再验证有声/无声混排、440/880Hz 顺序、短音轨补齐、静音、原片不变及总时长。端到端对成片提取 PCM，验证真实非零声音采样，而不是仅检查文件或音轨存在。
4. 浏览器覆盖声音编辑、刷新持久化、多行音效键盘输入、清除角色声音设定、完整生成、成片下载、ZIP 解包与历史台词保留。

独立审查发现并复现两项 P2，均先补失败测试再修复，复审未发现新增 P1/P2：

- 角色只保留声音描述时，删除会留下悬空引用。现在服务端阻止删除，页面提供清除入口并要求先保存分镜；未保存草案不能删除角色。
- 对音视频分别使用 PTS-STARTPTS 会把原片延迟 0.5 秒的声音提前。改为公共时间原点和前导静音补齐；真实采样证明 0.1 秒静音、0.65 秒有声，总时长仍为 1 秒。

## 验收边界

真实 Pi SDK/HTTP、SQLite、FFmpeg 编解码与 Edge 浏览器执行；云端图像、视频与对象存储使用替身。演示有声镜头为 440Hz 测试音，不朗读台词，不是 AI 配音。本轮不调用真实收费生成服务。

HeyGen 官方说明 Video 1 支持原生场景声音，OpenRouter 实时目录的 generate_audio=false 与介绍存在歧义；原生 API 文档没有该开关。省略开关后的实际路由行为、中文对白/旁白、口型、逐字准确性与跨镜头音色，仍需在页面确认费用后单镜头实测。无音轨响应会明确失败，不伪装成有声成功；存在音轨也不代表台词内容已验证。

独立 TTS、声音克隆、自动台词转写验收、口型修复、全片配乐混音、M3 视觉审查与自动修复均未交付。对象存储仍使用既有 S3 配置；没有配置不会提交新的真实图生视频费用。

本地合成不产生云端费用。云端失败不保证供应商不计费，费用以实际账单为准；应用不会自动重生成弥补语音缺陷。
